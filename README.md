# Страница-переходник для входа VK ID → программа ZARABARA ИСТОРИЯ на этом компьютере (http://localhost:53682/vk). Ничего не хранит.

## Собственное мини-приложение VK

`mini.html` — отдельная экспериментальная страница для **своего VK Mini App**, а не приложения VK ID.
Её адрес задаётся для веб-платформы в настройках мини-приложения:
`https://zarabarahorosho.github.io/zarabara-istoriya-auth/mini.html`.

Страница работает внутри VK, по нажатию пользователя вызывает `VKWebAppGetAuthToken` с единственным scope `stories`.
Проверяет наличие `stories` в ответе, показывает ключ маскированно и позволяет пользователю скопировать его в программу.
Нет серверного приёма ключей, аналитики, localStorage, cookie или автоматической публикации.
Ключ из памяти убирается при закрытии, очистке и не позднее чем через 30 минут; это не отзыв уже выданного доступа.
Программа отдельно проверяет профиль и `account.getAppPermissions` перед сохранением, а затем перед отправкой.
Истёкший ключ нужно получить заново: offline/refresh разрешение этот способ не запрашивает.

**На реальном аккаунте выдача ключа и публикация этим способом ещё не проверены.**
Приложение VK ID 54891189 нельзя считать готовым Mini App. Нужны собственное мини-приложение и подтверждение доступа пользователем.

Библиотека `@vkontakte/vk-bridge` 3.0.2 включена локально в `vendor/`, лицензия MIT сохранена рядом.
SHA-512 пакета проверен по npm integrity; происхождение и версия записаны в `vendor/vk-bridge-source.json`.
Официальный исходник: https://github.com/VKCOM/vk-bridge/tree/master/packages/core.
