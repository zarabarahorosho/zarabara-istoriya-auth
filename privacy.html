Описание работы с данными в настольной программе ZARABARA ИСТОРИЯ. Обновлено 14 ноября 2026.

Какие данные нужны программе

Программа обрабатывает добавленные владельцем видео, имена файлов, подписи, расшифровки, описания, теги и выбранные обложки. Для подключённых аккаунтов сохраняются название, идентификатор, разрешения доступа и история результатов публикаций.

Исходные материалы, подготовленные файлы и история находятся в папке данных на компьютере владельца. Доступы аккаунтов хранятся локально: YouTube и другие OAuth-токены — в защищённом хранилище ОС; сессия связанного устройства WhatsApp — в зашифрованном виде с ключом в хранилище ОС.

Google и YouTube

Программа использует YouTube API Services. Вход выполняется через Google OAuth. Программа не получает пароль Google. Разрешения используются для определения подключённого канала, загрузки выбранных видео и обложек, проверки их обработки, оформления и доступа, а также открытия подтверждённых публикаций для всех.

Google может описывать разрешение управления видео шире, включая оценки, комментарии и субтитры. Приложение использует его для описанных выше функций публикации и проверки. Сохранённый refresh token позволяет продлевать доступ без нового входа, пока Google разрешает это.

Данные, полученные через YouTube API, не продаются и не используются программой для рекламного профилирования. Для работы с ними действуют правила Google API Services User Data Policy, включая ограничения использования данных.

Также действуют Условия использования YouTube и Политика конфиденциальности Google.

Другие сервисы

При публикации выбранные материалы передаются соответствующей соцсети. Telegram-пульт принимает материалы и команды владельца. Включаемая отдельно HTTPS-загрузка больших видео использует Cloudflare для передачи файла с телефона на компьютер.

При использовании редактора Codex и генерации обложек расшифровка, выбранные кадры и запросы передаются OpenAI через подключённый профиль. Это отличается от локальной расшифровки видео. На сервисы сторонних поставщиков распространяются их собственные условия и политики.

Как прекратить доступ и удалить данные

Подключение можно удалить в разделе «Аккаунты» программы. Разрешение Google можно отозвать в настройках сторонних подключений Google. После отзыва программа не сможет продолжить работу с этим разрешением. Уже опубликованные видео от этого не удаляются; ими можно управлять в YouTube.

Локальные видео, подготовленные материалы и история остаются на компьютере владельца. Их удаление выполняет владелец в своей папке данных. С вопросами об удалении или обработке данных можно обратиться по адресу поддержки ниже.
